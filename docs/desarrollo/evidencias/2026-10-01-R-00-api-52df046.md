## Fallos

Ninguno en esta ejecución. Durante la entrega se corrigieron, antes de esta ejecución:

- **Fecha efectiva.** El runtime podía fijar `effective_at`. Ahora no tiene `INSERT` sobre esa columna ni sobre `created_at`, así que no hay retrofechas.
- **Asientos.** La política de inserción solo comprobaba el espacio. Ahora exige que el asiento pertenezca a una operación del actor del contexto.
- **Cursor del historial.** Se derivaba de un `Date` de JavaScript, que pierde microsegundos. Ahora sale de SQL con precisión completa.
